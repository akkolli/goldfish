# Code of conduct

Goldfish welcomes contributors with different backgrounds and levels of experience. Treat each other with respect, explain technical disagreements, and make room for new contributors.

## Expected behavior

- Discuss ideas and code without personal attacks.
- Give clear, constructive feedback and accept corrections in good faith.
- Respect privacy. Use synthetic examples instead of real clipboard contents.
- Avoid discriminatory language, harassment, threats, sexualized content, and unwanted contact.
- Respect people's time and decisions about participation.

These expectations apply to project issues, discussions, pull requests, reviews, and other project spaces. Maintainers may edit or remove inappropriate content, lock conversations, warn participants, or restrict participation. Responses should be proportionate to the behavior and its impact. Maintainers are subject to the same expectations.

## Reporting concerns

Use GitHub's **Report content** or **Report abuse** controls for harassment or other conduct concerns. See [GitHub's reporting guidance](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam). For a public moderation request that contains no private details, mention [@akkolli](https://github.com/akkolli) in the affected project conversation. Do not post personal information or contact someone who has asked you to stop.

Security vulnerabilities have a separate [private reporting channel](SECURITY.md). No public contact email is listed for this project.
